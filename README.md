# SYNTAXIS: FRACTAL GENESIS

**A fully procedural tech demo ROM for the Sega Mega Drive / Genesis.**

> NO PRECOMPUTED LEVELS — ONLY GENERATED SCENES

Не игра, а непрерывная последовательность сцен в духе демосцены 90-х:
консоль «в реальном времени» строит мир из простейших примитивов.
Вся графика — тайлы, спрайты, палитры, 3D-каркасы — генерируется кодом
при старте сцен и на лету. В репозитории нет ни одного графического ассета.

## Сцены

| # | Сцена | Что показывает |
|---|-------|----------------|
| 1 | BOOT | `NEURAL ROM COMPILER v0.1 / GENERATING WORLD...` — терминал, печатная машинка |
| 2 | BIRTH | пустота → сетка → один треугольник → глаз; камера начинает вращаться |
| 3 | CITY | ИИ на лету достраивает каркасный 3D-город, орбита камеры |
| 4 | FRACTAL | город схлопывается в рекурсию — фрактал Серпинского растёт по глубине |
| 5 | TUNNEL | полигональный тоннель летит на камеру, жёсткий palette cycling |
| 6 | LANDSCAPE | псевдо-Mode7: пер-строчный H-scroll превращает плоскость в 3D-пол |
| 7 | METROPOLIS | векторный мегаполис — бешеный многослойный параллакс, резкие смены планов |
| 8 | SWARM | 80 аппаратных спрайтов (предел VDP) в перестраивающихся формациях + масштабирование |
| 9 | NUKE | процедурный ядерный гриб: разгорающаяся точка света → цветной плазменный шар, размазывающийся по всему экрану → вспышка → кучерявое облако с молниями, ударными волнами и обломками |
| 10 | RAIN | цифровой дождь из сгенерированных примитивов |
| 11 | FINALE | мир «ломается»: глитч → распад на треугольники → белый экран → `ROM GENERATED 100%` |
| 12 | FLOWER | эпилог: трёхмерный RGB-цветок падает с неба, как цветок Ран в Texhnolyze — маятниковый дрейф, залитые дизером лепестки отрываются строго на даунбит, copper-градиент заката |
| 13 | TREE | Древо Жизни: фрактальное дерево прорастает корнями и кроной, поверх — 10 сфирот и 22 пути; Солнце и Луна друг напротив друга, как Яхин и Боаз |
| 14 | ALEPH | большая иврит **א** штрих за штрихом — и ничего лишнего |
| 15 | MYTH | искра падает с ночного неба, касается земли — и поджигает следующий сгенерированный мир |

После финала демка перезапускается с новым сидом — мир каждый раз
генерируется немного другим. START пропускает текущую сцену.

## Технологии

- [SGDK](https://github.com/Stephane-D/SGDK) — C + m68k gcc
- Программный битмап-движок SGDK (256×160, двойная буферизация) для векторных сцен
- Пер-строчный горизонтальный скролл (line scroll) для псевдо-Mode7 и глитчей
- Синус-таблица генерируется на старте целочисленной аппроксимацией Бхаскары — во всём проекте нет ни одного float и ни одной предвычисленной таблицы
- **FM-движок**: прямой драйвер YM2612 с 68000 (Z80 остановлен) — 6 FM-каналов + 3 PSG + шум звучат одновременно. Оригинальная композиция в духе Jesper Kyd / Red Zone: acid-бас с настоящим портаменто (глиссандо между нотами одного регистра — та самая «квакающая» acid-house squelch-текстура), рейв-гейт на отдельном PSG-канале (пульсирующая педаль под грувом), гритти FM-тембры (растущий фидбэк, резкий rave-стаб, индастриал-кик). Секции calm/drive/hard/agony/mythic переключаются сценами; визуал синхронизирован с битом через хуки секвенсора (`seq_isKick`, `seq_isDownbeat`)
- **Графика на пределе**: залитые сканлайн-треугольники и диски/эллипсы с бесплатным дизерингом (2 пикселя на байт BMP) — все заливки используют быстрый битовый integer sqrt вместо линейного поиска, поэтому кадр не проседает даже при большом количестве заливок за раз; copper-градиенты неба через HInt (смена цвета фона каждые 8 строк, только в тайловых сценах — в BMP-сценах градиенты рисуются прямо в битмап), Shadow/Highlight в мегаполисе, бэкфейс-куллинг, губка Менгера и фрактальные деревья, line-scroll дисторшны

## Сборка

С установленным SGDK (переменная `GDK` указывает на него):

```sh
make
```

Через Docker (официальный образ SGDK):

```sh
make docker
```

Готовый ROM: `out/rom.bin`. CI (GitHub Actions) собирает ROM на каждый push
и выкладывает артефакт `syntaxis-fractal-genesis`.

## Запуск

Любой эмулятор Mega Drive: [BlastEm](https://www.retrodev.com/blastem/),
Genesis Plus GX, Fusion — или настоящее железо через флеш-картридж
(Everdrive и т.п.).

```sh
blastem out/rom.bin
```
